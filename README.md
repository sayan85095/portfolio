# Sayan Mukherjee — AI & ML Engineer Portfolio 🚀

Official Futuristic Portfolio of **Sayan Mukherjee**, B.Tech Student in Computer Science & Engineering (Artificial Intelligence & Machine Learning) at Brainware University.

## 🌟 Features
- **3D Neural Canvas**: Three.js WebGL interactive 3D particle background.
- **Cyber System Boot Loader**: Animated OS initialization sequence.
- **AI Assistant Chatbot**: Interactive embedded chatbot answering queries about Sayan's skills & projects.
- **Project Showcase**:
  - **PlantBot AI**: Sub-1.8s Keras CNN crop leaf disease detection platform with Gemini LLM & Ollama Llama 3 integration.
  - **Hand Gesture Control System**: Touchless HCI computer automation powered by OpenCV & MediaPipe.
  - **ML Algorithm Explainer**: Interactive Streamlit application explaining ML decision boundaries.
  - **AI Health ChatBot**: Healthcare NLP symptom guidance assistant.
- **Certificate Modal Viewer**: High-definition interactive viewer for SIH 2025, Samsung AI, and AI Drone certificates.
- **Eye-Friendly Soft Light / Cyber Dark Themes**: Smooth theme switcher with high-contrast harmonious palettes.
- **Interactive Guestbook & Working Contact Form**: Web3Forms API integration with copy-to-clipboard utilities.
